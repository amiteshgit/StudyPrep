# StudyPrep

Interview questions with **simple answers and working code**. Each answer starts with a short line you can say out loud, then explains the idea behind it.

## Pick a page

| Page | What is inside |
| --- | --- |
| [Spring Boot](./spring-boot-interview.md) | 45 questions: basics, beans, configuration, web, data and transactions, production, security, testing, modern Boot, and design scenarios |
| [Java](./java-interview.md) | 48 questions: core language, strings, collections, generics and streams, memory and the JVM, concurrency, modern Java, and design |

## How to use these pages

1. Read one section at a time. The sections are in an order that builds on itself.
2. Use the list on the right side of each page to jump to a question.
3. Run the code snippets yourself. Answers you have tried are easier to explain.
4. Look for the boxes: **tip** (good habit), **warning** (common trap), **note** (extra detail).

More pages will be added here as the guide grows.
