## How to use these pages

1. Read one section at a time. The sections are in an order that builds on itself.
2. Use the list on the right side of each page to jump to a question.
3. Run the code snippets yourself. Answers you have tried are easier to explain.
4. Look for the boxes: **tip** (good habit), **warning** (common trap), **note** (extra detail).

More pages will be added here as the guide grows.
